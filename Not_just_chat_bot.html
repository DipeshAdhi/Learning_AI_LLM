Module 01

Procedural Memory: Agent Skills

Stop using monolithic system prompts. Agent Skills provide a modular framework for injecting procedural knowledge—how to perform specific tasks—without bloating the context window.

Progressive Disclosure

The agent doesn't load everything at once. It indexes metadata first, then loads the body only when a semantic match occurs.

Module 03

Computational Economics

Agents resend their whole context on every step, so a long loop pays for the same tokens dozens of times. Caching the stable prefix is the single largest lever on that bill — and the one most teams never pull.

The Power of Prefix Caching

Prompt caching reduces latency by 85% and slashes input costs by 90% by storing Key-Value (KV) tensors. Success depends on placing static data at the absolute beginning of the prompt.
